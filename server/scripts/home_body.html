The forensic workflow · NIST SP 800-86

From one victim's phone to a syndicate case

  1. 01

    1. Collection

    Victims send chats, screenshots, proof of payment and voice notes on the web or Telegram. The town where they were scammed decides the bank branch fraud desk.

    Report a scam →
  2. 02

    2. Examination

    Each original is stored read-only with a SHA-256 fingerprint and a hash-chained custody log, so any change is detectable.

    Verify a file →
  3. 03

    3. Analysis

    Accounts, numbers, links and scripts are extracted and compared by keyed hash across every branch. Shared signals become explainable leads, never verdicts.

    How linking works →
  4. 04

    4. Reporting

    A sealed case pack and a syndicate report go to the bank. The lead branch merges the cases, blocks the mule account and escalates to SAPS.
