The evidence workflow

From scam to case file, in four steps

  1. 01

    Collect

    Send chats, screenshots, proof of payment and voice notes on the web or Telegram. We never ask for your ID number or GPS.

    Report a scam →
  2. 02

    Preserve

    Each original is stored read-only with a SHA-256 fingerprint and a hash-chained custody log, so any change is detectable.

    Verify a file →
  3. 03

    Analyse

    Accounts, numbers, links, amounts and a timeline are extracted and labelled unverified. Shared signals become explainable leads, never verdicts.

    How linking works →
  4. 04

    Report

    Get a draft statement in your language, a bank fraud letter and a case pack PDF to take to the station. No case number until SAPS registers it.

    Track a case →
