SAPS sees the syndicate; the bank can freeze the account while the money is still there.

The forensic workflow

From one victim's phone to a syndicate case

  1. 01

    Collect

    Victims send chats, screenshots, proof of payment and voice notes on the web or Telegram. The town where they were scammed decides the station jurisdiction.

    Report a scam →
  2. 02

    Preserve

    Each original is stored read-only with a SHA-256 fingerprint and a hash-chained custody log, so any change is detectable.

    Verify a file →
  3. 03

    Link

    Accounts, numbers, links and scripts are extracted and compared by keyed hash across every jurisdiction. Shared signals become explainable leads, never verdicts.

    How linking works →
  4. 04

    Act

    The lead station consolidates the dockets; the bank gets a signed mule-account alert and its decision flows back. Case packs carry a QR code for the station handover.

    Syndicate board →
